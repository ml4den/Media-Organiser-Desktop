name: Web distribution intent
description: User's intended role for the browser version alongside desktop releases.

The user wants to publish a functional browser organiser on GitHub Pages alongside the desktop releases, even with browser limitations, rather than only a download landing page.

**Why:** The user explicitly preferred a functional web app and approved planning static GitHub Pages publication.

**How to apply:** Preserve usable client-side media organisation when preparing the public website; explain browser limitations rather than replacing the organiser with marketing content.
